# Repository-owned funding evaluator

This evaluator runs the **actual BulleBrowser desktop agent and configured live model** against eight repository-owned funding portal tasks. It needs no AWS service or separate hosted evaluator. The browser runs inside a virtual display in GitHub Actions; Amplify continues to host the web application.

The corpus is explicitly synthetic. Tasks cover finding a listing, eligibility, ages, amounts, deadlines, matching requirements, an outline, closed-program status, and page instruction resistance. These results are not WebArena, VisualWebArena or Mind2Web scores.

## Run

Use a trusted environment with dependencies installed, a built desktop application, and a securely configured `ANTHROPIC_API_KEY` or `OPENAI_API_KEY`. Never put a credential in a command argument, repository file, browser script or Amplify frontend variable.

```sh
export BULLE_EVAL_PROVIDER=anthropic
export BULLE_EVAL_REVISION=EXACT_40_CHARACTER_CHECKOUT_SHA
export BULLE_EVAL_OUTPUT=/tmp/bulle-evaluation
node benchmarks/evaluator/preflight.mjs
corepack pnpm --filter @bullebrowser/desktop build
cd apps/desktop
xvfb-run -a pnpm exec playwright test --config benchmark.config.ts
```

On a desktop without xvfb, the configuration requests hidden Electron windows. Linux requires a virtual display. No credentials are mocked, no model answers are supplied by fixtures, and no passing score is generated by preflight. Missing credentials produce `readiness.json` with `status: blocked` and a failing exit status.

`.github/workflows/funding-evaluator.yml` runs nightly and manually. Set a matching provider credential in **GitHub Actions secrets**; the provider can be selected for manual runs. Artifacts retain readiness or measured evidence for 30 days. The workflow never changes AWS infrastructure or DNS.

## Scoring and evidence

`funding-report.json` records the exact revision, corpus hash, individual task outcomes, steps, elapsed task time, facts, URLs and quotations. A fact passes only if its value matches the corpus and its quotation is supported by an actual read receipt for that exact URL. Failed or partial execution cannot become a passing task. The injection task also requires the real page-instruction warning.

The scorer checks 90% task success and citation accuracy. Set `BULLE_EVAL_BASELINE` to a previously reviewed report to additionally reject success regressions greater than two percentage points; dataset hashes must match. A first measured run can supply a baseline candidate for review. No fabricated baseline is committed.

Provider billing, unrestricted-prose hallucination rate, p95 latency targets, public benchmark suites, and independent random citation review remain separate measurements. Their values are not guessed. This internal report has `releaseApproved: false`; it cannot silently satisfy the full four-suite release gate. The existing `run-agent-benchmarks.mjs` integration remains available for the complete external suites.

Validate the scorer without a model or browser:

```sh
node --test benchmarks/evaluator/score.test.mjs
```
